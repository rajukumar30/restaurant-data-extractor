# PlaceExtract — Restaurant Data Extractor

A basic single-restaurant web app. Paste a Google Maps URL, look up the place with Google Places API (New), preview available details/photos/reviews, and download JSON or CSV.

See the full setup and limitations in this README. Configure `GOOGLE_MAPS_API_KEY` in your hosting provider (for Vercel, add it under Project Settings → Environment Variables). Never expose it with a `NEXT_PUBLIC_` prefix.
